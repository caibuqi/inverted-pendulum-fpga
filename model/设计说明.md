## 1. 系统辨识: 这是"旋转倒立摆"(Furuta 摆)

```
摆杆(要立起来) ── SA100 角位移传感器(铰链处, 测倾角 theta)
      │
   摆臂(水平旋转臂)
      │
  水平云台 / 直流电机+编码器(竖轴, 测 phi 及转速)
      │
   固定底座
```

| 物理量 | 符号 | 传感器 | 说明 |
|---|---|---|---|
| 摆杆倾角 | θ | SA100 (PWM 输出) | 0 = 正立, π = 自然下垂 |
| 摆杆角速度 | θ̇ | θ 差分+滤波 | 噪声是最大敌人 |
| 摆臂转角 | φ | 电机编码器积分 | 对应"定点位置" |
| 摆臂角速度 | φ̇ | 编码器测速 | 对应"电机转速" |
| 控制量 | u | PWM 占空比 | −1 ~ +1, τ = Kt·u − Ke·φ̇ |

**关键结论(决定模型对不对)**: 摆杆必须是在**垂直于摆臂**的竖直平面内摆动。
- 这样摆臂的切向加速度 `r·φ̈` 直接落在摆杆的摆动平面内 → 一阶可控;
- 若摆杆在**包含摆臂**的平面内摆动, 摆臂角加速度方向垂直于摆动平面,
  一阶上对摆杆**完全无作用**(只剩 φ̇² 离心项), 直立点线性化后**不可控**,
  那种结构根本无法用常规方法平衡。
- 数值验证: 两种线性化模型的能控性秩都是 4/4(见脚本第 3 节), 但只有前者
  的耦合系数 `c = m·r·l ≠ 0` 让输入进入 θ̈。

## 2. 动力学模型

广义坐标 `q = [φ, θ]`, 状态 `x = [φ, θ, φ̇, θ̇]`:

```
M(q)·q̈ = F(q, q̇)

M = [[ J + m·l²·sin²θ ,  m·r·l·cosθ ],
     [ m·r·l·cosθ     ,  A          ]]

F = [ τ − 2·m·l²·sinθcosθ·θ̇·φ̇ + m·r·l·sinθ·θ̇² ,
      m·l²·sinθcosθ·φ̇² + m·g·l·sinθ              ]

J = J_arm + m·r²      摆臂(含电机转子折算)绕竖轴转动惯量
A                     摆杆绕自身转轴转动惯量
c = m·r·l             耦合系数
Δ = J·A − c²
```

**实验参数(首轮估计)**: r=0.09 m, L=0.26 m, m=0.05 kg, l=0.156 m, A=1.577e-3,
J=6.05e-4, c=7.02e-4, Δ=4.615e-7, Kt=0.15 N·m, 空载 31.4 rad/s → Ke=4.777e-3。

**两个必须记住的解析结论**:
```
θ̈ = (J·m·g·l·θ − c·τ) / Δ        ← c≠0 才有控制作用
倒立不稳定极点 = sqrt(m·g·l/A) = 6.96 rad/s (1.11 Hz)
```

### 自检(脚本自动跑)
1. 总机械能 `dE_total/dt` 必须等于 `(Kt·u − Ke·φ̇)·φ̇` —— 残差 ~1e-11 ✓
   **注意**: `Ke·φ̇` 是反电动势耗散项, 期望值漏掉它就会误判模型不自洽。
2. 无电机无摩擦时总机械能守恒 —— 相对误差 2.69e-14(机器精度) ✓

## 3. 控制架构: 级联(外环给加速度, 内环管速度)

```
外环 1kHz:  alpha_des(角加速度需求) ──积分──► dphi_cmd(角速度给定)
内环 1kHz:  PI + 反电动势前馈 + 库仑摩擦死区补偿 ──► u(占空比) ──► 电机
```

**为什么不用纯力矩直控**: 摆臂惯量极小(`Kt/J ≈ 500 rad/s²`), 纯力矩 bang-bang
会把摆臂甩成飞轮 —— 摆臂动能 `½Jφ̇²` 在 φ̇=20 时达 0.63 J, 是摆杆能量尺度
`m·g·l = 0.0765 J` 的 8 倍, 能量在摆臂和摆杆之间来回倒, 永远泵不上去(实测失败)。

**平衡环** 用"角加速度输入"模型设计 LQR:
```
φ̈  = alpha
θ̈  = (m·g·l/A)·θ − (b_pen/A)·θ̇ − (c/A)·alpha
```
好处: 增益不依赖电机参数(J, Kt, Ke), 只依赖机械参数, 对电机参数不确定更鲁棒。

**R 的选择不能拍脑袋**: LQR 增益必须让**最快闭环极点明显小于内环速度环带宽**,
否则等于要求执行机构做它做不到的事 —— 增益再大也只会抖和饱和。
实测: R=1.11e-5(α_max=300) → 最快极点 518 rad/s, 而速度环带宽只有 70 rad/s,
结果平衡出现 1.9° 极限环且起摆抓住后发散。**扫描后选 R=6.94e-3**。

### 最终增益(★估计参数下)
```
Ka = [-75.895, -1230.083, -41.294, -175.72]     [phi, theta, phidot, thetadot]
alpha_des = -Ka·x        Q = diag(40, 500, 1, 10), R = 6.944e-3
闭环极点 = [-21.2, -7.07, -4.35±2.38j]          (最快 21.2 << 速度环 70)
人话: 1° 倾角 → alpha = 21 (rad/s²)/deg
```
内环: `kp=0.25, ki=3.0`, 闭环时间常数 14.3 ms(带宽 70 rad/s);
死区补偿 `u_dead = tc_arm/Kt × 1.3 ≈ 0.087`。

## 4. 起摆: 振幅判据 + 满功率泵 (踩过的坑最多)

### 能量泵的正确相位
```
dE/dt = −c·cosθ·θ̇·φ̈   (E = ½Aθ̇² + m·g·l·cosθ, E* = m·g·l)
⇒ φ̈ = −A_sw·sign(cosθ·θ̇)  恒定使 dE/dt > 0
```
`|θ̇|` 最大(摆杆过最低点)时泵功率最高, 所以**必须在最低点出力**。

### ✗ 错误做法 1: 速度 bang-bang `φ̇_cmd = A·sign(θ̇cosθ)`
速度指令只在**符号翻转瞬间**产生加速度, 而翻转点正是 `θ̇=0` —— 泵功率恒为 0。
实测: 摆 6 秒能量赤字纹丝不动。

### ✗ 错误做法 2: 积分形式 `φ̇_cmd = k·(E−E*)·sinθ`
这是做法 3 的时间积分, 数学等价, 但**幅值被乘上了 sinθ**, 在最低点归零
→ 加速度≈0 → 起摆没劲。实测: 死锁在下垂点。

### ✗ 错误做法 3: 能量判据
摆臂速度大时耦合项 `m·l²·sinθcosθ·φ̇²·θ̇` 可达 **0.37 W, 是泵功率的 5 倍**,
把能量估计彻底搅乱, 控制器永远收敛不到捕获窗口。

### ✓ 最终做法: 振幅判据
- 满功率泵能量 `φ̈ = −A_sw·sign(cosθ·θ̇)`;
- 在返回点(`θ̇` 变号)锁存当前 `|θ|` 作为**摆幅**(距顶点角), 这个量**不受耦合项污染**;
- 摆幅 < 阈值(0.20 rad)就停止泵能量, 只留回中+阻尼, 等平衡环接管;
- 另加 `|θ̇| > 14 rad/s` 护栏防甩飞, `|φ| > 1.6 rad` 软墙保证不越界。

### ★ 起振激励(必须有, 否则永久死锁)
摆杆"自然下垂"时落在**转轴静摩擦死区**内: 死区 = `tc_pen/(m·g·l)` = 1.5°,
重力力矩 1.5 mN·m **小于**静摩擦 2 mN·m → 摆杆根本不动; 而 `θ̇=0` 又让能量律
输出 0 → **死锁**。解决办法: 先用 ±4 rad/s、3 Hz 方波抖动摆臂把它晃出来,
`|θ̇| > 0.5 rad/s` 后切到正常起摆律。

## 9. 赛题约束与工程权衡

- **"旋转臂转角 ≤ 90°"** 与**起摆速度**是直接冲突的:
  泵功率 `P = c·|cosθ|·|θ̇|·|α|`, 而摆臂半周期位移 `≈ ¼·α·(T/2)²`。
  实测 α_sw_max=40 时摆臂扫到 208°; 压到 90° 需要 α ≤ 13 rad/s²,
  起摆时间会从 ~7 s 拉长到 ~15 s。
  → 需要用真实参数重算, 再决定要不要牺牲起摆速度换行程合规。
- 当前实现已带 `|φ| > 1.6 rad` 软墙, 保证失控时也不越界。
