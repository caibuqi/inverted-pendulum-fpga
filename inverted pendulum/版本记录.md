## 状态机（照抄示例）
| mode | 示例 RunState | 动作 |
|---|---|---|
| 0 | 0 | 停止，PWM = 0（显示模式 3 可用 K5/K6 点动） |
| 1 | 1 / 21..24 / 31..34 | **判断 + 启摆** |
| 2 | 4 | **平衡**：10 ms 角度环 + 50 ms 位置环 |

**mode 1 启摆细节**（每 40 ms 采样一次角度，存 3 个点）：
- 三次采样全部在某一侧、且**中间那次是极值** → 摆杆到了那一侧的最高点
- 左侧最高点 → 先给 **+35 %** 占空比 100 ms（手臂向右），再 **−35 %** 100 ms 回位
- 右侧最高点 → 先给 **−35 %** 100 ms（手臂向左），再 **+35 %** 100 ms 回位
- 连续 2 次采样落进中心区间的 ±43.9 度 → 进入 mode 2（清积分、手臂位置归零）
- 刚启动时立刻踢第一脚（示例里按 K1 后马上进状态 21）
- 15 s 起不来就放弃；摆杆不动 600 ms 会先踢一脚脱离死点
- 只起摆一次（掉下来就停，重新拨 SW1 再来）

## 平衡细节
- 进入平衡时：积分清零、`phi_cap` 取当前手臂位置（位置环从这里算 0）
- **保护写在直立环里**：直立环的「输入」= 摆杆相对直立中心的差值，
  绝对值超过 **45 度**（`GUARD_DEG = 450`）就把 PWM 输出设为 0；
  差值回到 45 度以内自动恢复出力 —— **不停机、不锁死**（`BAL_GUARD_EN = 1`）
- 保护窗口外同时把积分清零，免得憋一大坨积分
- 位置环目标：K3/K4 微调 1/8 圈，K5/K6 微调 1 圈，K7 归零；限幅 ±10 圈

## 串口调参（115200 8N1，Type-C / CH340，pin49=RX, pin48=TX）
增益**填整数**，实际增益 = 数字 / 9362（**Ki 在此基础再 ÷10**）：
```
[s,Z_KP,136]     角度环 Kp = 0.0145  (默认 136, 已调定)
[s,Z_KI,10]      角度环 Ki = 0.00107 (默认 10, 已调定)
[s,Z_KD,75]      角度环 Kd = 0.0080  (默认 75, 已调定)
[s,target,181]   直立中心角度 181 度
[s,Z_SGN,1]      翻转平衡输出方向 (1 = 翻转, 0 = 恢复)
[s,W_KP,1638]    位置环 Kp2 = 0.40  (Q12, 默认 0)
[s,W_KD,16384]   位置环 Kd2 = 4.00  (Q12, 默认 0)
```
- 格式：`[` `s` `,` 名字 `,` 数字 `]` —— **数字后面直接是 `]`，不要加逗号**
- 范围 0 ~ 10000（超过的包会被丢掉）
- 每包原样回显 + CRLF，看到回显才算接受（**只回显一次**，以前会无限重复刷）
- **参数读回**：发 [s,GET,1]，板子回一行十六进制:
  A0088 B000A C004B D0000 E0712
  A=Z_KP(0x88=136)  B=Z_KI(0x0A=10)  C=Z_KD(0x4B=75)  D=Z_SGN(0)  E=target(0x712=1810)
  调好后发这一条，就能把板子里的真实参数抄下来（W_KP/W_KD 暂不在读回里）

## 方向怎么确认（重要）
默认极性是「摆杆偏向哪边，手臂就往哪边追」。
**DIP2 (pin 76) 推上**（只平衡）+ 手扶摆杆接近竖直，**轻轻往一边偏**：
- 手臂朝**偏向的那一边**追 → 方向对
- 手臂朝**反方向**跑 → 串口发 `[s,Z_SGN,1]` 翻转，不用重编

## 启动开关（DIP 拨码）
```
DIP4 (pin 79) 推上 = 启动, 起摆 + 平衡     拨下 = 停止
DIP2 (pin 76) 推上 = 启动, 只平衡(不起摆)  拨下 = 停止
DIP1 (pin 75) 已损坏 —— 程序里不再使用
```
- 起摆模式下推上开关时会重新学一次 SA100 零点（以摆杆当前位为下垂 0 度），
  所以推开关时摆杆要垂着
- 只平衡模式不动零点（沿用上电学到的）

## 硬件接线要点
- 电机 TB6612：PWM=41, AIN1=42, AIN2=46
- 编码器：A=43, B=44（1040 计数/圈）
- SA100：PWM 输入 = 45
- 按键：K1=56, K2=59, K3=60, K4=61, K5=62, K6=63, K7=64, K8=65
- 拨码：SW1=75(坏), SW2=76(只平衡), SW3=77, **SW4=79(启动)**
- 串口：RX=49, TX=48
- 蜂鸣器：已关闭
